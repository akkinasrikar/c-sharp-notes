## ✅ **Basic Topics Covered**

### 1. **Namespaces**
- Organizing code using the `namespace` keyword.

### 2. **Class Definition**
- Defining a class (`Program`) as the main building block.

### 3. **The `Main` Method**
- Entry point of a C# console application.

### 4. **Console Input and Output**
- `Console.WriteLine()` for displaying messages.
- `Console.ReadLine()` for reading user input.

### 5. **Type Conversion**
- `int.Parse()` to convert string input to integer.

### 6. **Arrays**
- Declaring and using arrays to store temperature and conditions.

### 7. **Random Number Generation**
- Using the `Random` class to generate pseudo-random temperatures.

### 8. **Conditional Statements**
- Using `if`, `else if`, and `else` to assign conditions based on temperature.

### 9. **Loops**
- `for` loops to populate and display array data.
- `foreach` loops to process arrays/dictionaries.

### 10. **Methods**
- Creating and calling custom `static` methods (`AverageTemperature`, `MostCommonWeatherCondition`).

### 11. **Return Types and Parameters**
- Understanding return values (`float`, `string`) and method parameters (arrays).

### 12. **String Interpolation**
- Using `$"..."` syntax to embed variables in strings.

### 13. **Built-in Data Structures**
- Using `Dictionary<string, int>` to count occurrences of conditions.

### 14. **LINQ Methods**
- Using `.Max()` and `.Min()` to find extreme values in arrays.

### 15. **Access Modifiers**
- Using `static` for utility methods shared across the class.
