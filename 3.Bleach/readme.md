### ✅ **C# Topics Covered**

#### 1. **Classes and Objects**
- Creating custom classes (`Bleach`)
- Instantiating objects with `new`
- Organizing code using namespaces

#### 2. **Constructors**
- Constructor overloading
- Assigning values at the time of object creation

#### 3. **Properties**
- Auto-implemented properties (`Name`)
- Read-only properties (`Description`)
- Write-only properties (`Bankai`)
- Backing fields (`_bankai` for `Bankai`)

#### 4. **Access Modifiers**
- `private`, `public`, `internal`, and `readonly` usage
- Understanding encapsulation

#### 5. **Fields**
- `static` fields (`nextID`)
- `const` fields (`Villan`) — compile-time constants
- `readonly` fields (`Hero`, `id`) — runtime constants

#### 6. **Control Flow**
- `if`, `else if`, `else` for conditional logic
- Using string comparisons to assign values

#### 7. **Methods**
- Instance methods (`DisplayInfo`)
- Static method (`Main` in `Program`)

#### 8. **Keyword Usage**
- `this` keyword to refer to instance members
- `new` keyword for object instantiation

#### 9. **Console I/O**
- `Console.WriteLine()` for output
- Understanding flow of output with method calls and property access

#### 10. **Error Prevention Concepts**
- Trying to modify a `readonly` property (compile-time error)
- Attempting to use a write-only property in a read context (compile-time error)
