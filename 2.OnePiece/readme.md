## 📚 Topics Covered

This project demonstrates the following foundational concepts in C#:

### 1. Namespaces  
Understanding how to organize code into logical groups to prevent naming conflicts.

### 2. Classes and Objects  
Creating custom types using classes and instantiating them into objects.

### 3. Constructors and Constructor Overloading  
Using constructors to initialize objects and overloading them to allow multiple ways of object creation.

### 4. Access Modifiers  
Utilizing access modifiers (`public`, `private`, `internal`) to control the visibility and accessibility of class members.

### 5. Properties and Fields  
Distinguishing between fields and properties, and implementing auto-implemented and custom properties.

### 6. Encapsulation and Validation  
Protecting internal state through encapsulation and using validation logic in property setters.

### 7. Static Members  
Declaring and using static fields and methods that belong to the class rather than instances.

### 8. Instance Methods  
Creating methods that operate on specific instances of a class.

### 9. Method Accessibility (Private/Public)  
Understanding the difference between private helper methods and public interface methods.
